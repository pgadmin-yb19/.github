## PostgreSQL Admin Overview

pgAdmin is the definitive companion to PostgreSQL, maintained alongside the database itself. Its web-based architecture means the same interface runs as a desktop app or a shared server, adapting to solo developers and teams alike.

The platform exposes the full richness of Postgres: schemas, roles, tablespaces, extensions, and more appear in an organized browser tree. Each object has property dialogs that map directly to the underlying SQL, so nothing about the server stays hidden.

Beyond administration, pgAdmin ships a capable query tool with an explain visualizer, a graphical query builder, and dashboards that chart server activity. This makes it a single destination for writing SQL, tuning performance, and managing the cluster.

## Getting Started Playbook

Install pgAdmin or open its hosted instance, then set a master password to protect saved credentials. Right-click servers and choose register to add a connection with host, port, maintenance database, and login.

Expand the new server to reveal its databases and schemas. Open the query tool from the toolbar to run SQL, or select any object and use its properties dialog to alter it. The dashboard tab gives an immediate pulse on server health.

## Everyday Use

For daily operations, DBAs rely on pgAdmin to watch the dashboard for locks and long queries, run ad-hoc SQL in the query tool, and manage roles and grants, keeping a busy Postgres cluster healthy from one browser tab.
